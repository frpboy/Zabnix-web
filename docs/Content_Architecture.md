# Content Architecture

This document maps out the core copy, headings, and structure of the Zabnix corporate website. It serves as the single source of truth for marketing copy, positioning, and content modules across all pages.

---

## 1. Global Copy Guidelines
* **Tone**: Professional, technical, confident, clean, modern, and direct.
* **Heading Style**: Sentence-case, period-terminated for display headers (e.g. "Build faster. Automate smarter.").
* **Casing**: Title Case for primary navigation buttons and CTA pills.
* **Capitalization Ceiling**: Weight 600 sans-serif is the typography ceiling. No all-caps display headers.
