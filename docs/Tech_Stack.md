# Tech Stack Specification
Project: Zabnix Corporate Website

## Core Technologies

### Frontend
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI
- **Animations:** Framer Motion

### Backend & Database
- **API Layer:** Next.js Server Actions / Route Handlers
- **Database:** PostgreSQL
- **Database Host:** Neon (Serverless Postgres)
- **ORM:** Prisma

### Infrastructure & Deployment
- **Hosting:** Vercel
- **Storage:** AWS S3 or Vercel Blob (for media, resumes, case study images)
- **Email Delivery:** Resend (for contact forms, demo requests)

## Extended Ecosystem (Zabnix Capabilities Showcase)
As part of the company's broader service offerings displayed on the site, the following technologies are highlighted:
- **Mobile Apps:** Flutter, React Native, Firebase
- **Backend/AI:** Python, Node.js, FastAPI
- **Cloud/DevOps:** Docker, AWS, Azure
